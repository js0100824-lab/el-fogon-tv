# Caliente TV

Página con transmisión en vivo, noticias y redes.

- `index.html`: la página
- `noticias.json`: noticias, link del directo y redes (se reemplaza cada vez que publicas cambios)
- `logo-*.png`: logos

Para publicar cambios: Admin > Publicar > Descargar noticias.json y súbelo al repositorio reemplazando el anterior.
